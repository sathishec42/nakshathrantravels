# Nakshathran Travels — Vehicle Booking Demo

This updates the sample React app to include a simple Material UI (MUI) dashboard-style page with:

- Travel posters
- A listing of vehicles (one sample vehicle: Force Urbania DX 4400 12-seater)
- Sample tariffs (per day / per km)

Notes
- Vehicle specs were taken from the link you provided and tariff numbers are sample estimates. Update the tariffs in `src/data/vehicles.js` if you have exact pricing.

Run locally:

1. npm install
2. npm start
